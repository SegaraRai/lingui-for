`t` は、Lingui における主要な文字列生成マクロです。
呼び出し箇所でメッセージを翻訳し、その結果の文字列を返します。

翻訳済みラベル、見出し、インラインテキストが欲しく、埋め込みマークアップが不要な場合に使ってください。
リンクや強調を含むリッチテキストなら、代わりに [`Trans`](/ja/macros/trans-component) コンポーネントマクロを使います。

フレームワークに依存しない Lingui の意味論については、[公式の `t` リファレンス](https://lingui.dev/ref/macro#t) を参照してください。

## 使い方

<Tabs syncKey="framework">
  <TabItem icon="seti:svelte" label="Svelte">

```svelte
<script lang="ts">
  import { t } from "lingui-for-svelte/macro";

  let name = $state("Lingui");
</script>

<p>{$t`Hello ${name}`}</p>
```

`.svelte` ファイルでは `$t` を使います。
アクティブなロケールが変わると自動で再評価されます。
素の `t`（`$` なし）はコンパイル時エラーです。

この仕組み、`$derived` を使う場面、`t.eager` というエスケープハッチについては [リアクティブマクロ](/ja/frameworks/svelte/reactive-macros) を参照してください。

  </TabItem>
  <TabItem icon="astro" label="Astro">

```astro
---
import { t } from "lingui-for-astro/macro";

const name = "Lingui";
---

<p>{t`Hello ${name}`}</p>
```

`.astro` における `t` は、リクエスト単位で評価される非リアクティブな形式です。

  </TabItem>
  <TabItem icon="seti:javascript" label="Official Lingui">

```ts
import { t } from "@lingui/core/macro";

const name = "Lingui";

const label = t`Hello ${name}`;
// -> "Hello Lingui" または、アクティブなロケールに応じた同等の文字列
```

## `t` が向いている場面

- すぐに翻訳済み文字列が欲しい
- メッセージがテキストまたは文字列テンプレートとして自然に書ける
- リッチテキスト構造が主目的ではない

## `t` と `msg` のネスト

Lingui 6.6 以降では、別のコアマクロの中に書いた `t` や `msg` のタグ付きテンプレートは、別々の翻訳呼び出しにはならず外側のメッセージへインライン展開されます。
これにより、`plural` や `select` の選択肢に補間を含めたい場合に `msg` を使えます。

```svelte
<script lang="ts">
  import { msg, plural, t } from "lingui-for-svelte/macro";

  let count = $state(1);
  const books = msg`You have ${plural(count, {
    0: msg`No books`,
    one: msg`One book`,
    other: "# books",
  })}`;
</script>

<!-- "Field First Name is required" として抽出される -->
<p>{$t`Field ${$t`First Name`} is required`}</p>
<p>{$t(books)}</p>
```

`.astro` ファイルの `t` でも同様です。
Lingui 6.5 以前では内側のマクロは別に翻訳され、外側のメッセージには `{0}` のような位置プレースホルダーとして渡されます。
